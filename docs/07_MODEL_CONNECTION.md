# 모델 연결: 개인 OpenAI·Claude API 키

각 팀원이 자기 PC에서 EduFlow를 실행하면 화면 상단의 연결 배지에서 **모델 연결** 창을 열 수 있습니다. 무료 데모, OpenAI API 키, Claude API 키 중 하나를 선택합니다. 키는 이 PC의 `.eduflow-private/connection.json`에만 저장되며 화면에는 마지막 네 자리만 표시합니다. 폴더 권한은 700, 파일 권한은 600이고 Git에서 제외됩니다.

| 방식 | 결제 | 보호 장치 |
| --- | --- | --- |
| 무료 데모 | 없음 | 외부 AI 전송 없음 |
| OpenAI API 키 | 키 소유자의 OpenAI 계정 | 이 PC의 하루 $1·월 $5 한도와 입력·출력 토큰 상한 |
| Claude API 키 | 키 소유자의 Claude Console 계정 | 같은 비용 장부, 최대 16,000 입력·8,000 출력 토큰 |

키를 입력하고 유료 호출 동의를 선택한 뒤 저장합니다. 저장된 키는 브라우저에 다시 보내지 않습니다. 기존 `.env.local`의 OpenAI 설정은 계속 사용할 수 있으며, 화면에서 OpenAI 키를 저장하면 그 키를 우선 사용합니다. 서버 설정과 저장 키의 비용 한도는 각 PC에서 별도로 적용되므로 팀 전체 사용량을 합산하지 않습니다. 여러 사람이 같은 서버를 쓰는 용도에는 사용자별 키 격리가 없습니다.

Claude 모델은 [공식 모델 목록](https://platform.claude.com/docs/en/models/overview)에 있는 Opus 5.5, Sonnet 5.5, Haiku 5.5만 선택합니다. 표준 100만 토큰당 입력·출력 가격은 각각 $4/$20, $2/$10, $0.10/$0.50입니다. Haiku 5.5는 100,000 입력 토큰을 넘으면 가격이 올라가므로 Claude 요청의 입력 한도를 16,000토큰으로 고정합니다. 기존 개인 설정이 이보다 낮으면 낮은 값이 유지됩니다. 기본 1회 예약 한도는 Opus $0.50, Sonnet $0.25, Haiku $0.02이며 팀 공통 하루 $1·월 $5 한도가 우선합니다.

비공개 저장소의 ChatGPT 플랜 로그인 기능은 포함하지 않았습니다. [OpenAI의 현재 안내](https://developers.openai.com/siwc/quickstart)는 플랜 사용을 공개 오픈소스 앱과 선정된 비공개 클라이언트에 제공합니다. Claude 구독 로그인을 앱에서 중계하는 기능도 포함하지 않았습니다. [Anthropic의 안내](https://code.claude.com/docs/en/legal-and-compliance)는 제품에 Claude.ai 로그인이나 구독 한도를 제공하려는 개발자에게 API 키 인증을 사용하도록 요구합니다.

키와 인증 값은 채팅·소스 코드·GitHub에 입력하지 마세요. 키를 제거하면 화면 저장본이 삭제됩니다. 실제 제공자 계정으로 호출하는 검증은 키 소유자의 명시적인 테스트 요청이 있을 때 별도로 진행합니다.
