# 모델 연결: 개인 OpenAI·Claude API 키와 Gemini 팀 키

각 팀원이 자기 PC에서 EduFlow를 실행하면 화면 상단의 연결 배지에서 **모델 연결** 창을 열 수 있습니다. 무료 데모, OpenAI API 키, Claude API 키, Gemini(팀 키) 중 하나를 선택합니다.

## Gemini 팀 키 (사용자는 키 입력 없음)

시연처럼 여러 사람이 키 없이 바로 써야 할 때는 운영자가 서버 PC의 `.env.local`에 팀 키를 한 번 넣습니다. 화면에는 키 입력칸이 없고, 키는 서버 설정 파일에만 있습니다.

1. Google AI Studio에서 Gemini API 키를 발급합니다(Google 계정 필요, 무료 등급 사용 가능).
2. 서버 PC의 `.env.local`에 아래를 넣습니다. 키는 채팅·소스 코드·GitHub에 넣지 않습니다.
   ```
   EDUFLOW_GENERATOR=gemini
   EDUFLOW_GEMINI_API_KEY=발급받은 키
   EDUFLOW_GEMINI_MODEL=gemini-3.8-flash
   ```
3. 서버를 다시 시작합니다. 처음 실행하는 PC는 바로 Gemini로 생성합니다. 이전에 연결 창에서 다른 방식을 고른 PC는 **모델 연결 → Gemini (팀 키)**를 한 번 선택합니다.

| 모델 | Google 무료 등급 | 유료 등급 가격(100만 토큰당 입력/출력, 2026-10-27 확인) |
| --- | --- | --- |
| `gemini-3.8-flash` (기본) | 사용 가능 | $0.75 / $3.75 (2027-01-01부터 $1.50 / $7.50) |
| `gemini-3.5-flash-lite` | 사용 가능 | $0.30 / $2.50 |

- **무료 등급:** 비용은 없지만 입력한 원고가 Google 제품 개선에 쓰일 수 있습니다. 공개해도 되는 자료로만 시연하세요. 무료 사용량 한도는 키가 속한 Google 프로젝트 단위이므로 같은 키를 쓰는 팀원이 함께 나눠 씁니다.
- **유료 등급:** Google 프로젝트에 결제를 연결하면 위 가격이 청구되고 입력이 학습에 쓰이지 않습니다. 결제 여부를 키만으로 알 수 없으므로 앱은 항상 유료 가격으로 비용을 예약해 이 PC의 하루 $5·월 $10 한도를 지킵니다.
- 입력 16,000·출력 8,000토큰 상한, 1회 호출(SDK 자동 재시도 끔), 생각 단계 `LOW`를 사용합니다. 생각 토큰도 출력 상한에 포함됩니다.
- 생성 시 원고·설정·선택 자료가 Google로 전송된다는 안내가 화면에 표시됩니다.
- 원고 또는 선택한 PDF를 주 자료로 사용하고, 지식베이스 검색 결과가 없거나 검색에 실패해도 원문 기반 생성을 계속합니다. 검색된 설명·그림 연결 정보는 보강 자료로 전달하며 원문 위치와 지식베이스 위치를 분리해 저장합니다.
- PDF 전체 생성은 선택 페이지를, ‘현재 출처’ 범위의 장면 재생성은 해당 원본 페이지만 전송합니다. 토큰 계산과 생성에는 같은 PDF와 원본 페이지 번호를 사용합니다.
- 모델과 단가는 [Google 모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)와 [공식 가격표](https://ai.google.dev/gemini-api/docs/pricing)를 2026-10-30에 대조했습니다. 위 3.8 Flash 도입 가격은 2026-12-31까지만 유효하므로 이후 사용 전 가격 설정을 갱신해야 합니다.

## 개인 OpenAI·Claude API 키

 키는 이 PC의 `.eduflow-private/connection.json`에만 저장되며 화면에는 마지막 네 자리만 표시합니다. 폴더 권한은 700, 파일 권한은 600이고 Git에서 제외됩니다.

| 방식 | 결제 | 보호 장치 |
| --- | --- | --- |
| 무료 데모 | 없음 | 외부 AI 전송 없음 |
| OpenAI API 키 | 키 소유자의 OpenAI 계정 | 이 PC의 하루 $5·월 $10 한도와 입력·출력 토큰 상한 |
| Claude API 키 | 키 소유자의 Claude Console 계정 | 같은 비용 장부, 최대 16,000 입력·8,000 출력 토큰 |

키를 입력하고 유료 호출 동의를 선택한 뒤 저장합니다. 저장된 키는 브라우저에 다시 보내지 않습니다. 기존 `.env.local`의 OpenAI 설정은 계속 사용할 수 있으며, 화면에서 OpenAI 키를 저장하면 그 키를 우선 사용합니다. 서버 설정과 저장 키의 비용 한도는 각 PC에서 별도로 적용되므로 팀 전체 사용량을 합산하지 않습니다. 여러 사람이 같은 서버를 쓰는 용도에는 사용자별 키 격리가 없습니다.

Claude 모델은 [공식 모델 목록](https://platform.claude.com/docs/en/models/overview)에 있는 Opus 5.5, Sonnet 5.5, Haiku 5.5만 선택합니다. 표준 100만 토큰당 입력·출력 가격은 각각 $4/$20, $2/$10, $0.10/$0.50입니다. Haiku 5.5는 100,000 입력 토큰을 넘으면 가격이 올라가므로 Claude 요청의 입력 한도를 16,000토큰으로 고정합니다. 기존 개인 설정이 이보다 낮으면 낮은 값이 유지됩니다. 기본 1회 예약 한도는 Opus $0.50, Sonnet $0.25, Haiku $0.02이며 팀 공통 하루 $5·월 $10 한도가 우선합니다.

비공개 저장소의 ChatGPT 플랜 로그인 기능은 포함하지 않았습니다. [OpenAI의 현재 안내](https://developers.openai.com/siwc/quickstart)는 플랜 사용을 공개 오픈소스 앱과 선정된 비공개 클라이언트에 제공합니다. Claude 구독 로그인을 앱에서 중계하는 기능도 포함하지 않았습니다. [Anthropic의 안내](https://code.claude.com/docs/en/legal-and-compliance)는 제품에 Claude.ai 로그인이나 구독 한도를 제공하려는 개발자에게 API 키 인증을 사용하도록 요구합니다.

키와 인증 값은 채팅·소스 코드·GitHub에 입력하지 마세요. 키를 제거하면 화면 저장본이 삭제됩니다. 실제 제공자 계정으로 호출하는 검증은 키 소유자의 명시적인 테스트 요청이 있을 때 별도로 진행합니다.
