# RAG 지식베이스: 동작 방식과 자료 등록 기록

## 동작 방식

README에 있던 설명을 옮겨 왔다(2026-10-27 정리).

AI 생성은 첫 장면을 위험·질문으로 시작하는 도입부, 가운데 장면을 주제·절차별 정보전달부, 마지막 장면을 핵심 수칙과 실천 행동을 되짚는 마무리로 구성하도록 요청합니다. `/knowledge`에서 공식·내부 자료를 PDF·DOCX·TXT 또는 텍스트로 등록하면, 서버가 구간과 PDF 원본 페이지를 보존해 `.eduflow-private/knowledge.sqlite`에 색인합니다. 큰 PDF는 필요한 원본 페이지 범위를 지정해 등록할 수 있습니다. 공식 자료에는 원본 URL이 필수입니다. 생성할 때 서버가 원고와 관련된 활성 구간을 검색하고, 관련 근거가 없으면 원고만으로 생성하고 편집 화면 상단에 "보강 자료 없음"을 표시합니다(2026-10-27 변경, 이전에는 생성을 중단). AI가 사용했다고 표시한 출처는 장면 아래 **보강 자료 근거**에 원문 근거와 분리해 표시하고 Markdown·CSV에도 포함합니다. 데모 모드는 원문 발췌 방식이므로 지식베이스를 사용하지 않습니다.

지식베이스는 처음에는 비어 있습니다. 검색은 영구 저장된 원문 구간에 대한 한국어 3글자 검색 인덱스(FTS5)를 사용하며, 자동 웹 수집이나 벡터 임베딩은 하지 않습니다. 발행일·판본은 등록 시 입력한 값을 보존하고 자료를 검색에서 제외하거나 다시 활성화할 수 있습니다. 기존 임시 하드코딩 자료는 삭제했습니다. 모델의 출처 ID는 실제 검색 결과인지 서버가 검사하지만 문장별 사실 관계와 최신 법령 여부까지 자동 검증하지는 않습니다. 실제 제작 전 원문·외부 자료·현재 법령을 함께 확인하세요.

## 자료 등록 기록

지식베이스의 원문과 색인은 각 PC의 `.eduflow-private/knowledge.sqlite`에 저장하며 Git에는 올리지 않는다. 아래 기록은 동일한 공식 원본을 다른 PC에서도 등록할 수 있도록 남긴다.

| 자료 | 원본 | 발행·판본 | 등록 범위 |
| --- | --- | --- | --- |
| 고용노동부 「2023년 대·중소기업 안전보건 상생협력사업 운영 매뉴얼」의 SIF 고위험요인 통제 가이드 | [안전보건공단 게시 PDF](https://oshri.kosha.or.kr/kosha/data/healthandsafetyf.do?articleNo=441256&attachNo=250367&mode=download) | 2023년 8월, 1차 개정 | PDF 파일 기준 11페이지 |

`/knowledge`에서 원본 PDF, 위 URL·발행 정보, 페이지 범위 `11`을 등록하면 원본 페이지 번호를 보존한 구간이 색인된다. 등록 후 `고소작업 추락 위험 안전난간`으로 검색해 11페이지가 나오는지 확인한다.

이 자료의 해당 페이지는 추락 위험 장소의 방호 조치와 작업 전 점검을 설명한다. `고소작업의 종전 기준은 2m였고 사람 머리 강도를 바탕으로 정했다`는 주장은 이 페이지에 없으므로 보강 문장에 넣지 않는다. 법령이나 수치의 현재 효력은 별도로 확인한다.
