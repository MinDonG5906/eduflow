## 기준과 변경

- `storyboard`의 기존 Frame 소스와 `01_MVP_PRD.md`를 기준으로 복구했다.
- EduFlow 워드마크, E 심볼, 파비콘, 페이지 제목, 도움말·푸터, 패키지명을 적용했다.
- 첨부된 Expo 디자인 참고를 흰 바탕, 검정 CTA, 얇은 테두리, 상단의 하늘색 배경으로 반영했다. 세부 원칙은 `EDUFLOW_DESIGN.md`에 있다.
- 입력·설정 → 장면 편집 → 내보내기, 장면 편집·이동·재생성, 자동 저장, Markdown·CSV 변환 로직을 유지했다.
- 장면 미리보기는 편집 중인 제목과 자막을 즉시 보여준다.
- 기존 localStorage 키 `frame-studio-v1`을 유지한다. 저장 데이터는 같은 브라우저와 같은 origin에서 이어진다.
- 모바일 메뉴에 포커스 순환·Escape 닫기·배경 조작 차단을 적용하고, 모바일에서도 검토 필터를 사용할 수 있게 했다.
- 개발 미리보기의 스타일 갱신 문제를 확인하여 개발 서버도 Webpack으로 실행한다.

## 확인한 동작

- TypeScript 검사, 프로덕션 빌드, 핵심 로직 자동 테스트 4개 통과.
- 샘플 원고 입력 → 3장면 생성 → 제목·자막 편집 → 미리보기 반영.
- 2번 장면 재생성 후 1번 장면의 수정 제목·자막 유지.
- 새로고침 후 전체 제목과 수정된 장면 복구.
- Markdown 전체 복사에 수정 제목·자막 포함.
- 모바일 메뉴의 Shift+Tab 포커스 순환, Escape 닫기, 메뉴 버튼으로 포커스 복귀.
- 모바일 페이지와 화면 너비 동일: 실제 CSS 너비 354px에서 가로 넘침 없음. 데스크톱 입력·편집 화면도 시각 확인.
- 내보내기 모달의 파일명·3개 형식·검토 필요 수 표시.

브라우저 도구에서 파일 다운로드 이벤트를 확인하지 못했다. Markdown·CSV 문자열은 자동 테스트로 검증했으며 실제 파일 저장은 일반 브라우저에서 추가 확인할 수 있다. 실제 AI 모델 연결·품질 평가는 이번 복구 범위에 포함하지 않았다.
