# 시청자 언어(외국인 근로자) 지원 계획

작성일: 2026-11-02. 상태: 언어 선정과 설계 확정, 구현 전(Phase 2 이후).

## 1. 대상 국적 조사 (울산)

울산의 취업 체류자격(E-9·E-7·H-2·E-10) 전체를 국적별로 합산한 공식 순위는 찾지 못했다. 아래 두 자료를 조합해 상위 5개 국적을 정했다.

| 자료 | 기준 | 내용 |
| --- | --- | --- |
| 울산시 '다문화가구·외국인 통계' 분석 ([파이낸셜뉴스, 2025-12-30](https://www.fnnews.com/news/202512301102232960)) | 2024년 E-9 6,510명 | 스리랑카 1,119명(17.2%), 캄보디아 825명(12.7%), 필리핀 797명(12.2%), 베트남 730명(11.2%). 5위 이하는 기사에 없음 |
| 동남지방통계청 '울산 외국인의 현황 및 특성' ([뉴시스, 2025-09-23](https://www.newsis.com/view/NISX20250923_0003340044)) | 2024년 체류외국인 34,168명 | 한국계 중국인 27.8%, 베트남 18.3%, 중국 7.1% 순 (근로자만의 수치가 아님) |

같은 파이낸셜뉴스 기사는 2025년 11월 말 E-9 약 7,800명, E-7 약 5,300명이라고 적었지만 E-7·H-2의 국적 분포는 없다. 조선업 E-7 인력의 국적 구성은 확인하지 못했다.

**선정한 상위 5개 국적:** 스리랑카, 캄보디아, 필리핀, 베트남, 중국(한국계 포함).

- E-9 상위 4개국과, 전체 체류자에서 비중이 큰 중국(한국계 중국인은 H-2 방문취업 비중이 큼)을 합쳤다.
- 정확한 순위가 필요하면 법무부 출입국·외국인정책 통계월보의 시도·국적·체류자격별 원자료로 다시 확인한다.

## 2. 지원 언어

| 국적 | 언어 | 문자 | 표시 위험도 |
| --- | --- | --- | --- |
| 베트남 | 베트남어 (vi) | 라틴 문자 + 성조 부호 | 낮음 |
| 필리핀 | 영어 (en) | 라틴 문자 | 낮음 (이미 지원) |
| 중국·한국계 중국인 | 중국어 간체 (zh-Hans), 쉬운 한국어 (ko-easy) | 한자 / 한글 | 낮음 (한국계 중국인은 쉬운 한국어로도 대응) |
| 스리랑카 | 싱할라어 (si) | 싱할라 문자 | 높음 (결합 문자) |
| 캄보디아 | 크메르어 (km) | 크메르 문자 | 높음 (결합 문자, 띄어쓰기 없음) |

필리핀어(fil)와 타밀어(ta, 스리랑카 일부)는 후보로 둔다. 필리핀 근로자에게 영어가 널리 쓰이고, 원어민 검토자가 없는 상황에서 번역 품질을 가장 안정적으로 확인할 수 있어서 영어를 먼저 쓴다.

## 3. 원어민 검토자 없이 운영하는 원칙

원어민 검토자가 없으므로 다음 장치로 오역 위험을 줄인다. 출력물에 검토 상태 문구는 넣지 않는다.

1. **한국어 원본 우선:** 한국어 원본을 검토한 뒤에 번역한다. 번역은 원본 장면 구조·시간·근거를 공유하는 별도 층(localizations)으로 저장한다.
2. **역번역 대조:** 번역할 때 한국어 역번역을 함께 받아 원본과 나란히 표시한다. 한국어 기획자가 의미 차이를 확인한다.
3. **코드 검사(추가 AI 호출 없음):** 장면 수·ID 일치, 목표 문자 사용, 숫자 보존, 자막 줄 수, 역번역 유무. 원문 근거는 번역 요청에 넣지 않는다.
4. **안전 용어집:** 안전보건공단 다국어 자료 등 공식 출처의 용어를 기준으로 하고, 현장 지시어는 한국어를 함께 적는다. 예: `Đội mũ bảo hộ (안전모)`. 현재는 번역 지시로 한국어 병기만 요구한다. 공식 용어 목록과 일치 검사는 아직 없다.
5. **중요 문장 보수적 처리:** 금지·필수 행동, 수치, 비상 절차가 들어간 문장은 짧은 문장으로 쓰고 한국어 원문을 함께 남기는 이중 자막을 기본으로 한다.

## 4. 구현 단계

| 단계 | 내용 |
| --- | --- |
| Phase 1 (완료) | 편집 화면 보완: 미리보기 가림 수정, 자막 탭 기본, 제목 줄바꿈, 생성 조건·검토 진행 표시 ([디자인 가이드](EDUFLOW_DESIGN.md)) |
| Phase 2 (완료) | 전체 대본 보기: 모든 장면의 나레이션·자막을 한 화면에서 읽고 고친다 |
| Phase 3 (완료) | 언어 목록(`lib/languages.ts`), 글꼴 번들, `Intl.Segmenter` 줄바꿈, PDF·PNG 다국어 표시 (6장) |
| Phase 4 (완료) | `/api/localize`(`eduflow-localization-v1`), 번역·역번역 생성, 위 3장의 코드 검사, 비용 장부 공유. 명세는 [AI 명세](03_AI_SPEC.md)의 번역 절 |
| Phase 5 (완료) | 대본 보기의 '시청자 언어' 선택, 한국어 원본·번역 나란히 편집, 역번역·경고 표시, 원본 수정 시 '원본 수정됨' 표시, 나눠서 번역·취소 |
| Phase 6 | 언어별 PDF·PNG·Markdown, 이중 자막, SRT/VTT 자막 파일 |
| Phase 7 | 다국어 평가 케이스, 문서·Windows 패키지 갱신 |

Phase 3에서 다섯 언어 모두 PDF·PNG 표시를 확인했으므로 Phase 4에서 함께 연결할 수 있다.

## 5. 남은 결정과 확인

- 열린 PR #18(대상별 작성 규칙·프롬프트 템플릿)도 `generation-service.ts`·`openai-adapter.ts`·`provider-prompt.ts`의 지시문 부분을 고친다. 늦게 머지되는 쪽에서 충돌을 정리한다.
- 언어 추가는 언어마다 생성 호출 1회가 더 든다. 로컬 PC별 하루·월 비용 상한 안에서 한 번에 처리할 언어 수를 정해야 한다.
- 영상 앱 화면(UI)은 한국어로 유지한다. 바뀌는 것은 영상 콘텐츠(제목·나레이션·자막)다.

## 6. 다국어 표시 (Phase 3 결과)

같은 문장(베트남어·중국어·싱할라어·크메르어)을 세 가지 방식으로 그려 비교했다.

| 그리는 방식 | 싱할라어 | 크메르어 | 중국어 | 베트남어 |
| --- | --- | --- | --- | --- |
| pdf-lib 글자 (기존 PDF) | 결합 글자 깨짐, 보조 라이브러리 없이는 오류로 중단 | 대체로 정상 | 정상 | 글꼴 부분 포함(subset) 시 글자 누락 |
| SVG → PNG (기존 스토리보드 이미지) | 깨짐 | 아래 첨자 분리 | 정상 | 정상 |
| canvas `fillText` | 정상 | 정상 | 정상 | 정상 |

이에 따라 다음과 같이 바꿨다.

- **글꼴:** `public/fonts`에 Noto Sans Sinhala, Noto Sans Khmer, Noto Sans SC(GB2312 7,728자로 줄인 2MB 파일)를 넣었다. 모두 SIL OFL 1.1이며 라이선스 파일을 함께 둔다. Windows 패키지는 `public` 폴더를 그대로 복사하므로 별도 설치가 필요 없다.
- **PDF 글자:** 한국어 시스템 글꼴을 먼저 쓰고, 없는 글자는 Inter(베트남어 등 라틴 문자)와 Noto Sans SC(중국어)로 채운다. 보조 글꼴은 해당 언어가 문서에 있을 때만 전체를 포함한다. 싱할라·크메르 등 조합이 필요한 문자는 canvas로 그린 이미지로 넣는다. 이 줄은 PDF 안에서 글자로 검색되지 않는다.
- **스토리보드 이미지(PNG·PDF):** 제목 카드와 자막을 SVG 대신 canvas로 그린다.
- **줄바꿈:** 단어 단위로 나누고, 한국어·중국어는 기존처럼 글자 사이에서도 나눈다. 마침표·쉼표·크메르 문장부호(។)는 줄 처음에 오지 않는다.
- **자막 길이 검사:** 글자 수를 화면에 보이는 글자 단위(grapheme)로 센다.
- **화면 미리보기:** 브라우저는 SVG 이미지 안에서 설치된 글꼴만 쓴다. macOS(Sinhala/Khmer Sangam MN, PingFang SC)와 Windows(Iskoola Pota, Khmer UI·Leelawadee UI, Microsoft YaHei) 기본 글꼴 이름을 지정했다.
