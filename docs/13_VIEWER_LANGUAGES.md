# 시청자 언어(외국인 근로자) 지원 계획

작성일: 2026-11-02. 상태: 언어 선정과 설계 확정, 구현 전(Phase 2 이후).

## 1. 대상 국적 조사 (울산)

울산의 취업 체류자격(E-9·E-7·H-2·E-10) 전체를 국적별로 합산한 공식 순위는 찾지 못했다. 아래 두 자료를 조합해 상위 5개 국적을 정했다.

| 자료 | 기준 | 내용 |
| --- | --- | --- |
| 울산시 '다문화가구·외국인 통계' 분석 ([파이낸셜뉴스, 2025-12-30](https://www.fnnews.com/news/202512301102232960)) | 2024년 E-9 6,510명 | 스리랑카 1,119명(17.2%), 캄보디아 825명(12.7%), 필리핀 797명(12.2%), 베트남 730명(11.2%). 5위 이하는 기사에 없음 |
| 동남지방통계청 '울산 외국인의 현황 및 특성' ([뉴시스, 2025-09-23](https://www.newsis.com/view/NISX20250923_0003340044)) | 2024년 체류외국인 34,168명 | 한국계 중국인 27.8%, 베트남 18.3%, 중국 7.1% 순 (근로자만의 수치가 아님) |

같은 파이낸셜뉴스 기사는 2025년 11월 말 E-9 약 7,800명, E-7 약 5,300명이라고 적었지만 E-7·H-2의 국적 분포는 없다. 조선업 E-7 인력의 국적 구성은 확인하지 못했다.

**선정한 상위 5개 국적:** 스리랑카, 캄보디아, 필리핀, 베트남, 중국(한국계 포함).

- E-9 상위 4개국과, 전체 체류자에서 비중이 큰 중국(한국계 중국인은 H-2 방문취업 비중이 큼)을 합쳤다.
- 정확한 순위가 필요하면 법무부 출입국·외국인정책 통계월보의 시도·국적·체류자격별 원자료로 다시 확인한다.

## 2. 지원 언어

| 국적 | 언어 | 문자 | 표시 위험도 |
| --- | --- | --- | --- |
| 베트남 | 베트남어 (vi) | 라틴 문자 + 성조 부호 | 낮음 |
| 필리핀 | 영어 (en) | 라틴 문자 | 낮음 (이미 지원) |
| 중국·한국계 중국인 | 중국어 간체 (zh-Hans), 쉬운 한국어 (ko-easy) | 한자 / 한글 | 낮음 (한국계 중국인은 쉬운 한국어로도 대응) |
| 스리랑카 | 싱할라어 (si) | 싱할라 문자 | 높음 (결합 문자) |
| 캄보디아 | 크메르어 (km) | 크메르 문자 | 높음 (결합 문자, 띄어쓰기 없음) |

필리핀어(fil)와 타밀어(ta, 스리랑카 일부)는 후보로 둔다. 필리핀 근로자에게 영어가 널리 쓰이고, 원어민 검토자가 없는 상황에서 번역 품질을 가장 안정적으로 확인할 수 있어서 영어를 먼저 쓴다.

## 3. 원어민 검토자 없이 운영하는 원칙

원어민 검토자가 없으므로 번역문의 정확성을 사람이 보증할 수 없다. 다음 장치로 위험을 줄이고, 출력물에 미검토 상태를 숨기지 않는다.

1. **한국어 원본 우선:** 한국어 원본을 검토한 뒤에 번역한다. 번역은 원본 장면 구조·시간·근거를 공유하는 별도 층(localizations)으로 저장한다.
2. **역번역 대조:** 번역할 때 한국어 역번역을 함께 받아 원본과 나란히 표시한다. 한국어 기획자가 의미 차이를 확인한다.
3. **코드 검사(추가 AI 호출 없음):** 장면 수·ID 일치, 목표 문자 사용, 숫자·단위 보존, 원문 근거 미번역, 자막 폭.
4. **안전 용어집:** 안전보건공단 다국어 자료 등 공식 출처의 용어를 기준으로 하고, 현장 지시어는 한국어를 함께 적는다. 예: `Đội mũ bảo hộ (안전모)`.
5. **미검토 표시:** 번역 상태는 '원어민 미검토'로 시작하며 PDF·PNG·자막 파일에 표시한다. 검토자가 생기면 '검토 완료'로 바꿀 수 있게 한다.
6. **중요 문장 보수적 처리:** 금지·필수 행동, 수치, 비상 절차가 들어간 문장은 짧은 문장으로 쓰고 한국어 원문을 함께 남기는 이중 자막을 기본으로 한다.

## 4. 구현 단계

| 단계 | 내용 |
| --- | --- |
| Phase 1 (완료) | 편집 화면 보완: 미리보기 가림 수정, 자막 탭 기본, 제목 줄바꿈, 생성 조건·검토 진행 표시 ([디자인 가이드](EDUFLOW_DESIGN.md)) |
| Phase 2 | 전체 대본 보기(장면별 나레이션·자막 표), 편집기 재배치 |
| Phase 3 | 언어 목록(`lib/languages.ts`), 언어별 Noto 글꼴, `Intl.Segmenter` 줄바꿈, 미리보기·PNG·PDF 렌더링 스냅샷. 싱할라·크메르 문자를 pdf-lib이 올바르게 조합하는지 먼저 확인하고, 안 되면 Skia(@napi-rs/canvas)로 그린 이미지를 PDF에 넣는다 |
| Phase 4 | `/api/localize`(`eduflow-localization-v1`), 번역·역번역 생성, 위 3장의 코드 검사, 비용 장부 공유 |
| Phase 5 | 언어 탭, 원본·번역 나란히 편집, 원본 변경 시 '오래됨' 표시 |
| Phase 6 | 언어별 PDF·PNG·Markdown, 이중 자막, SRT/VTT 자막 파일 |
| Phase 7 | 다국어 평가 케이스, 문서·Windows 패키지 갱신 |

라틴 문자 언어(베트남어·영어)와 중국어·쉬운 한국어를 먼저 연결하고, 싱할라어·크메르어는 Phase 3 렌더링 검증을 통과한 뒤 연결한다.

## 5. 남은 결정과 확인

- 열린 PR #18(대상별 작성 규칙·프롬프트 템플릿)이 같은 파일을 수정한다. Phase 4 전에 머지 여부를 정해야 한다.
- 언어 추가는 언어마다 생성 호출 1회가 더 든다. 로컬 PC별 하루·월 비용 상한 안에서 한 번에 처리할 언어 수를 정해야 한다.
- 영상 앱 화면(UI)은 한국어로 유지한다. 바뀌는 것은 영상 콘텐츠(제목·나레이션·자막)다.
