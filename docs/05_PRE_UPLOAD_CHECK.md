## 발견 및 수정

### PDF 교체 후 이전 페이지 번호가 남음

3페이지 PDF를 열고 3페이지를 지정한 상태에서 1페이지 PDF를 올리면, 이전의 `3`이 남아 새 파일에 범위 오류가 발생했다. 새 PDF를 불러올 때 페이지 선택 컴포넌트를 새로 생성하도록 바꿨다. 파일 이름이나 수정 시각이 같은 재업로드도 별도의 불러오기로 취급한다.

같은 순서로 다시 시험하여 새 파일의 선택 범위가 비워지고, 1페이지 선택·미리보기·저장·새로고침 후 복구가 되는 것을 확인했다.

### 생성할 수 없는 조건에서 장면 재생성 버튼이 활성화됨

PDF가 준비되어 있으면 무료 데모에서도 장면 재생성 창이 열렸지만, 실행 단계에서 차단되어 아무 동작이 없는 것처럼 보였다. 전체 생성과 장면 재생성에 동일한 연결 상태·PDF 지원 여부·입력 완료·작업 중 상태 조건을 적용했다.

무료 데모의 PDF 재생성은 비활성화되고, 텍스트 원고의 전체 생성과 장면 재생성은 정상 실행되는 것을 확인했다.

### 내보내기 실패 안내가 열린 창 뒤에 가려짐

클립보드 복사가 실패해도 오류 안내가 내보내기 창 뒤에 있어 사용자가 바로 확인하기 어려웠다. 실패하면 내보내기 창을 닫고 오류를 표시하도록 바꿨다. 복사 실패 안내에는 권한 확인 또는 Markdown 다운로드 방법을 함께 적었다.

실패 처리의 창 닫기 경로를 코드로 확인했다. 수정 후 브라우저에서는 복사가 성공하여 최신 편집 내용이 클립보드에 포함되는 것까지 확인했다. 브라우저 권한을 강제로 변경해 실패를 재현하지는 않았다.
