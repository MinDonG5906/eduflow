# 표 구조와 원문 참고 시각자료 추천

## 별도 시각자료 선별 (2026-11-02)

글 근거 후보와 그림·표 후보를 각각 고른 뒤 같은 검증 호출에서 사실 근거와 시각자료 관련성을 구분해 판정한다. 기존 그림의 캡션이 원문에 실제로 있을 때만 조회 시 연결 후보를 보완한다. pending/rejected 연결은 덮어쓰지 않으며 후보를 검증 완료로 저장하지 않는다. 그림은 원본 크롭, 표는 실제 셀 구조를 유지한다. 관련성 대조를 통과한 개별 자료만 ‘참고 시각자료 추천’에 표시하고, 캡션을 사용한 그림에는 원본 확인 안내를 붙인다. 이미지 픽셀을 새로 판독하는 호출은 추가하지 않는다.

`feature/c-reference-backed-storyboard`에서 GPT-5.4 mini 기반으로 구현했습니다. 모델은 기존 서버 설정의 `gpt-5.4-mini-2026-03-17`을 사용합니다. nano 비교 평가를 완료했다는 의미는 아닙니다.

## 사용 순서

1. 지식 자료에서 PDF 또는 변환 가능한 문서를 등록합니다. 원본 PDF와 선택한 페이지 번호를 함께 보관합니다.
2. 자료의 **표와 시각자료**를 엽니다. 기존 PDF 자료는 **원본에서 표 구조 갱신 · 무료**로 구조를 다시 읽을 수 있습니다. 원본 파일이 없는 예전 텍스트 등록 자료는 원본 문서를 다시 등록해야 합니다.
3. 필요한 페이지의 **글·그림 연결 분석**을 실행합니다. 페이지 이미지, 그림 후보 잘라보기, 문장 후보가 OpenAI에 전송됩니다. 서버에 등록한 OpenAI 키와 유료 사용 설정이 필요합니다.
4. 표의 불명확한 기호는 해당 셀만 수정합니다. AI 판독 표는 원본과 비교하여 승인합니다. 불확실한 그림 연결은 그림·인용문 쌍별로 승인하거나 제외합니다. 판독 대기 페이지에서도 승인한 인용문이나 표만 검색됩니다.
5. 스토리보드 생성에서 관련 근거에 연결된 그림을 장면 카드로 추천합니다. 나레이션 보강 없이 그림만 선택할 수도 있으며 원문 페이지, 연결 문장, 추천 이유를 함께 표시합니다. 원문 위치와 지식베이스 위치를 별도로 확인할 수 있습니다.

## 보존과 추천 기준

- 선으로 구획된 PDF 표에서 행·열, `rowSpan`·`colSpan`, 빈 응답 칸을 보존합니다. 병합된 단계는 그 단계가 차지하는 각 행의 검색 근거에 반복합니다. 빈 YES/NO/N/A는 미기입이며 답을 추측하지 않습니다.
- 판독 불명 기호가 있는 행은 셀을 확인할 때까지 검색에서 제외합니다. AI가 읽은 표는 전체 셀 점유, 겹침, 누락을 검사합니다. 잘못된 표는 경고로 남기고 유효한 그림 연결은 저장합니다.
- PDF에 포함된 래스터 이미지의 좌표를 추출하고 렌더링된 페이지에서 잘라 보여줍니다. 벡터 그림이나 스캔 안의 그림은 모델 좌표 제안에 의존하며 작은 그림의 탐지가 보장되지 않습니다. 페이지 대부분을 차지하는 영역은 독립 그림으로 받지 않습니다.
- 존재하는 문장 ID와 원문에 포함된 인용문만 연결할 수 있습니다. 관련성이 명확하다고 모델이 분류하고 자체 신뢰도가 0.9 이상이며 검색 가능한 근거인 경우 추천 대상으로 삼습니다. 이 수치는 실측 정확도나 확률 보정 결과가 아닙니다. 그 밖의 연결은 확인 대기 또는 제외합니다.
- 그림에 연결된 인용문을 별도의 검색 근거로 반환합니다. 같은 페이지나 같은 긴 문단의 다른 문장을 인용했다고 그림을 자동 첨부하지 않습니다.
- 분석과 검토 결과는 로컬 SQLite에 저장합니다. 같은 분석을 열 때 유료 호출을 반복하지 않습니다. 문서 제외·삭제를 검색에 반영하며, 재검사 시 수동 승인 인용문과 수정·승인한 표를 보존합니다.
- 브라우저 작업 저장에 그림 메타데이터가 포함됩니다. Markdown에는 출처, 인용문, 추천 이유와 그림 좌표를 내보냅니다. 이미지 파일 자체는 내보내기에 포함하지 않으며 원본 자료를 삭제하거나 다른 PC로 옮기면 미리보기가 제공되지 않을 수 있습니다.

## 스토리보드 추천과 위치 확인 (2026-10-30)

- 실제 AI 생성은 지식베이스를 검색한 뒤 관련 구절을 `supplementalSources`로 전달합니다. 관련 구절이 없거나 지식베이스 검색이 실패·시간 초과(10초)되면 원문·첨부 PDF만으로 생성을 계속합니다. 결과에는 자료 활용·검색 결과 없음·검색 실패·미사용 상태를 구분해 표시합니다. 사용자 취소와 유료 AI 접근·예산·입력 제한은 그대로 적용합니다. 데모는 지식베이스를 검색하지 않습니다.
- 나레이션·자막 보강의 `referenceIds`와 그림 선택의 `visualReferenceIds`를 따로 받습니다. 같은 내용을 설명하는 그림도 새 사실 보강 없이 선택할 수 있습니다. 서버가 전달한 출처 중 확인된 그림이 있는 자료만 `visualReferences`와 그림 추천으로 저장합니다. 알 수 없는 출처와 그림이 없는 출처는 그림 추천에 쓰지 않습니다.
- 전체 생성 및 장면 생성 기록에 전달한 자료·구절 수를 저장합니다. 전체 생성 기록에는 검색 결과도 보관하며 장면에서 선택하지 않은 자료까지 위치 확인 창에서 열 수 있습니다. 이 수치는 AI에 전달한 검색 결과이며, 장면에서 선택한 보강 근거·그림 수와 구분해 표시합니다. 장면 재생성 시 이전 그림과 출처를 새 결과로 교체합니다.
- 원문 위치 확인은 입력 원고·업로드 문서, 지식베이스 위치 확인은 등록 자료를 대상으로 합니다. 후자는 생성 당시 인용문, 현재 구절 강조, 문서 제목·판본·원본 페이지와 등록 PDF 미리보기를 제공합니다. 원본 42페이지가 저장 PDF 첫 페이지여도 실제 저장 페이지 1을 엽니다. 본문 등록 자료에는 PDF 링크를 만들지 않습니다.
- 지식베이스 관리 링크는 해당 문서·원본 페이지·문장·그림을 선택합니다. 검색 제외 상태는 안내하고, 삭제되거나 이 PC에 없는 자료는 오류를 표시하되 저장된 인용문을 유지합니다. 자료가 바뀌어 인용문과 일치하지 않으면 일치한다고 표시하지 않습니다.
- 브라우저 저장과 Markdown 내보내기에 시각자료 출처를 보존합니다. 실제 유료 모델의 추천 품질 평가는 이번 변경의 자동 테스트 범위에 포함하지 않습니다.

## 분석 비용

페이지 분석은 최대 입력 16,000·출력 6,000 토큰이며 자동 재시도하지 않습니다. 동일한 요청의 토큰을 사전에 계산하고 기존 일·월·시간당 횟수 한도를 적용합니다. 기본 단가에서 페이지당 보수적 비용 상한은 $0.039이며 기존 장부의 두 시도 예약 방식에 따라 $0.078를 먼저 예약하고 미사용분을 반환합니다. 실제 청구액과 장부의 보수적 상한은 다를 수 있습니다. 분석 중 자료가 변경되면 오래된 결과로 덮어쓰지 않습니다.

## 2026-10-30 검증

실제 한국어 「작업 전 안전점검회의 가이드」의 원본 14·42·43·47페이지로 확인했습니다.

- 로컬 판독: 14페이지 단계표의 4·4·3행 병합과 47페이지 점검표의 빈 응답 칸을 확인했습니다. 14페이지의 해석 불명 글머리 기호는 셀별 확인 대상으로 남깁니다.
- 실제 mini 호출: 42페이지 그림 6개, 43페이지 로봇 그림 1개의 원문 영역을 분리하고 인용문 연결을 저장했습니다. 42페이지는 원문 판독이 불확실하여 연결별 승인이 필요합니다. 43페이지의 일부 연결은 확인 대기로 남았습니다.
- 한계: 42페이지 표는 로컬 판독과 모델 제안 모두 유효한 전체 표를 만들지 못해 검색 반영하지 않았습니다. 43페이지는 선으로 둘러싸인 표 영역을 읽지만 바깥쪽 분류 라벨까지 완전한 셀 구조로 묶지는 못합니다. 복잡한 표 전체를 자동 복원한다는 보장은 없습니다.
- 회귀 검사: 병합·빈 칸, 잘못된 표, 없는 인용문, 무관한 그림, 부분 승인·재검사·제외, 저장 후 복구, 비용 제한, 원본 잘라보기, 실제 인용 근거에서만 장면 그림을 추천하는 흐름과 두 내보내기 형식을 테스트합니다. 브라우저에서도 원본 그림 표시와 개별 승인 후 검색 색인 증가를 확인했습니다.

이번 확인은 제한된 문서 표본의 동작 검증입니다. mini/nano 비교나 정답셋 기반 연결 정확도 평가는 수행하지 않았고, OmniDocBench 점수를 그림·문장 연결 정확도로 사용하지 않았습니다.
