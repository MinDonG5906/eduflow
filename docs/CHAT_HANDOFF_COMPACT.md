# EduFlow Chat 인수인계 — Compact

기준일: 2026-09-29  
목적: 새 Chat/GPT 대화에서 최소한의 문맥으로 작업을 이어가기 위한 압축 자료

## 1. 한 줄 상태

EduFlow는 교육 원고를 스토리보드로 정리하는 **Next.js UX 프로토타입**이다. 입력 → 설정 → 장면 검토·편집 → 선택 장면 재생성 → Markdown·CSV 내보내기 흐름은 구현됐지만, 현재 생성은 **실제 AI가 아닌 원문 발췌 데모**다.

## 2. 제품 목표

교육 기획자가 원고를 근거로 제작 가능한 장면 구성, 화면 설명, 시각 자료 제안, 나레이션, 자막 초안을 빠르게 만들고 사람이 장면 단위로 검토·수정해 제작자에게 전달한다.

핵심 흐름:

```text
원고 입력 → 생성 조건 → 초안 → 장면별 검토·수정 → 부분 재생성 → 내보내기
```

## 3. 현재 구현

- 직접 입력·붙여넣기, UTF-8 TXT 불러오기
- 공백 제외 최소 100자, 전체 최대 20,000자 검증
- 대상·난이도·영상 길이·장면 수·톤·키워드·언어·추가 요청
- 콘텐츠 제목·요약·학습 목표와 장면별 필수 필드 표시
- 장면 목적·원문 근거·근거 위치·화면 설명·자료 제안·나레이션·자막·시간·검토 상태
- 모든 필드 직접 편집, 수정 필드 표시
- 선택 장면 재생성, 장면 추가·삭제·이동
- localStorage 자동 저장·새로고침 복구
- 전체 복사, Markdown·CSV 변환 및 다운로드 코드
- 모바일 레이아웃, 키보드 조작, 모달 포커스 관리
- TypeScript·빌드 통과, 자동 테스트 4개 통과

## 4. 중요한 한계

- `/api/generate`는 `generateDemo()`를 호출한다. 외부 AI·API 키·실제 번역은 없다.
- 결과는 원문 문장 분할과 고정 문구 조합이며 의미 기반 요약·재작성·자동 사실 검증이 아니다.
- 모든 생성 장면은 검토 필요로 시작한다.
- 실제 AI 품질, 대상·난이도 반영, 원문 왜곡, 시간 단축은 미검증이다.
- 저장은 같은 브라우저·같은 origin의 localStorage뿐이다. 서버 프로젝트 저장은 없다.
- 브라우저 다운로드 문자열은 테스트했지만 일반 Chrome/Safari 실제 파일 저장은 추가 확인이 필요하다.
- 로컬 프로토타입이며 공개 배포되지 않았다.

따라서 현재 상태를 **“UX 프로토타입 완료, AI 품질 MVP 착수 전”**으로 표현한다. “MVP 완료” 또는 “AI 품질 검증 완료”라고 표현하지 않는다.

## 5. 최근 결정

- 브랜드를 Frame에서 **EduFlow**로 변경했다.
- 반복 사용성을 위해 큰 소개 배너·장식용 목업·홍보 문구를 제거했다.
- 입력·편집 화면은 40px 제목줄과 주요 버튼만 두고 작업 내용을 위로 올렸다.
- 초보자 안내는 항상 노출하지 않고 `사용 가이드`로 제공한다.
- 디자인 원칙은 흰 바탕, 검정 CTA, 얇은 테두리, 압축된 작업 공간이다.
- 기존 저장 데이터 호환을 위해 localStorage 키 `frame-studio-v1`을 유지한다.
