# 문서 입력·원문 확인·브라우저 저장 상세

README에 있던 상세 설명을 옮겨 온 문서다(2026-10-27 정리). 요약과 실행 방법은 [README](../README.md), 생성 응답 규칙은 [03_AI_SPEC](03_AI_SPEC.md)을 본다.

## 원문 위치 확인

장면의 **원문 근거 → 원문 위치 확인**에서 원본 페이지와 해당 문장·구절을 확인할 수 있습니다. PDF·HWP·PPT는 브라우저에 저장된 선택본 전체를 로컬에서 검색하고, 일치 문장을 원문 이미지와 텍스트에 강조합니다. AI가 지정한 페이지와 일치 위치가 다르면 각각 표시하며, 여러 일치 위치를 앞뒤로 이동하거나 단어로 다시 검색할 수 있습니다. 페이지는 표지를 포함한 파일 순서, 구절 번호는 확인 보기의 순서입니다. 직접 입력·Word·TXT는 현재 원고의 문장을 확인합니다. 요약·의역으로 일치 문장이 없으면 찾지 못했다고 표시하고, 추출 가능한 글자가 없는 페이지는 이미지로 확인합니다. 검색·미리보기는 추가 AI 호출이나 토큰을 사용하지 않으며 원문은 외부로 전송하지 않습니다. `/api/documents/source` 응답은 저장하지 않고, 브라우저 메모리에 문서별 검색 결과를 재사용합니다.

## 업로드 공통 제한

문서 업로드의 고정 파일 용량 제한(기존 10MB)을 제거했습니다. 로컬 컴퓨터에서 처리하므로 실제 업로드·읽기 가능한 크기는 가용 메모리에 따라 달라집니다. 큰 문서가 1분 만에 중단되는 제한도 제거했으며, 불러오기 중 취소하면 기존 원고와 첨부 문서를 유지합니다. Word 문서의 비정상적인 압축 확장과 과도한 ZIP 항목 수 검사는 유지합니다. Word·TXT에서 추출한 글은 최대 200,000자, PDF는 최대 200페이지, 생성에 덧붙이는 원고는 최대 20,000자입니다.

## PDF

PDF는 **업로드 → 전체 장수 확인 → 전체 / 일부 선택(범위 예: 1, 3, 5-7) → 이 영역 사용 → 제작 요청 → 선택한 PDF로 생성** 순서입니다. 페이지 선택 중에는 AI를 호출하지 않습니다. 미리보기는 이 PC에서 렌더링하며, 전체 페이지를 세로 목록으로 배치해 마우스 휠로 확인합니다. 입력한 사용 영역은 목록에 표시되며 스크롤로 범위가 바뀌지는 않습니다. 화면 근처 페이지만 순차 렌더링하고 최근 이미지 최대 12장을 보관합니다. 선택을 확정한 뒤에는 선택본도 같은 방식으로 확인할 수 있습니다. 브라우저에서 선택 페이지만 새 PDF로 복사합니다. 생성 시 글자와 읽는 순서가 확실한 페이지는 원본 번호를 붙인 텍스트로 전달합니다. 표·그림·스캔·복잡한 배치 또는 추출이 불확실한 페이지는 보이는 내용을 고정한 호환 PDF 하나로 묶어 `input_file`로 전달합니다. 별도의 `input_image`는 첨부하지 않습니다. 텍스트만 있는 자료는 PDF 첨부 없이 전달할 수 있습니다. 원본과 브라우저에 저장한 선택본은 유지하며, 추출 원문과 전송용 호환본은 서버 메모리에서만 만듭니다. 시각 자료의 작은 글자는 원본과 대조해야 합니다. 선택본과 전송용 PDF는 각각 50MB 미만이어야 합니다. 실제 입력량이 서버 설정의 토큰 상한을 넘으면 측정한 입력량과 한도를 표시합니다. 무료 데모에서는 PDF를 해석하지 않습니다.

HWP·PDF·PPTX의 표 중심 페이지는 공통 PDF 분석 경로에서 셀 위치·행/열·병합 범위를 확인해 구조화합니다. 원문과 표 바깥 머리글·각주·강조색, 그림의 셀 연결을 보존합니다. 확인된 페이지에는 전체 배치 확인용 축소 이미지와 그림·체크 표시 영역의 고화질 이미지를 함께 보냅니다. 테두리 없는 표·복잡한 도해·스캔·회전·불확실한 경계는 기존 전체 페이지 호환 PDF를 사용합니다. 이는 변환된 PDF의 보이는 구조를 분석하는 기능입니다. 원본 페이지 번호와 장면 재생성 범위는 동일합니다. 실제 유료 생성 전 최종 입력 전체의 토큰 수를 계산하며, 모든 파일에 같은 절감률을 보장하지 않습니다.

장면 재생성은 현재 선택 자료에서 기존 출처를 확인할 수 있으면 기본적으로 해당 페이지만 참고합니다. 다른 페이지의 내용으로 바꾸려면 재생성 창의 **다시 참고할 자료 → 선택 자료 전체**를 선택하세요. 출처가 없거나 현재 자료와 맞지 않으면 선택 자료 전체를 사용합니다. 전체 생성과 형식 보완은 필요한 선택 범위를 유지하며, 요청 안의 토큰 계산·생성·보완은 추출 결과와 이미지 변환을 재사용합니다.

선택 PDF는 현재 브라우저의 IndexedDB, 파일명·원본 페이지 번호·제작 요청·원고·결과는 기존 localStorage에 저장합니다. 새로고침하면 선택본으로 계속 생성할 수 있으며, 다른 원본 페이지를 고르려면 원본 PDF를 다시 불러옵니다. 저장에 실패하면 현재 세션에서만 선택본을 사용하고 안내를 표시합니다. PDF·Word·TXT 업로드와 AI 생성은 서버 메모리에서 처리하며 OpenAI 파일 저장소에 보관하지 않습니다. PPT·한글 문서 변환 시에는 아래와 같이 임시 파일을 사용합니다.

## PPT/PPTX

PPT/PPTX도 **업로드 → 전체 장수 확인 → 전체 / 일부 선택(범위 입력) → 이 영역 사용 → 제작 요청 → 선택한 PPT로 생성** 순서입니다. 서버 PC의 LibreOffice로 PDF를 만든 뒤 기존 PDF 선택·미리보기·AI 전송 경로를 사용합니다. 업로드·변환·선택 중에는 외부 AI를 호출하지 않으며, 생성할 때 선택한 슬라이드를 같은 텍스트·시각 자료 분리 경로로 전달합니다. 원본 PPT 전체는 AI에 보내지 않습니다. 숨긴 슬라이드도 포함하여 원본 번호를 유지하고, 발표자 노트·댓글은 제외합니다. 동영상·애니메이션은 정적 화면으로만 표현되므로 그 재생 내용은 전달되지 않습니다. 글꼴이나 일부 배치가 PowerPoint와 달라질 수 있으므로 변환 미리보기를 확인해야 합니다. 최대 200슬라이드까지 불러올 수 있고, 실제 생성 가능한 장수는 선택본 50MB 미만·서버 입력 토큰 한도로 결정됩니다.

팀원 PC에는 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/)가 필요합니다. `soffice` 실행 파일을 PATH 또는 macOS·Windows 기본 설치 위치에서 찾으며, 다른 위치라면 `.env.local`의 `EDUFLOW_OFFICE_CONVERTER_PATH`에 실행 파일의 절대 경로를 지정하고 서버를 재시작하세요. 도구가 없으면 PDF로 저장해 올리도록 안내하며, 텍스트만 추출하는 방식으로 바꾸지 않습니다. 변환은 한 번에 하나, 최대 2분이며 취소·시간 초과·실패 시 변환 프로세스를 종료하고 임시 폴더를 정리합니다. 원본·변환본과 매크로 실행을 차단하는 전용 프로필을 임시 폴더에만 만들고 응답 후 삭제합니다. 기존 첨부 문서와 원고는 새 파일을 정상적으로 읽은 뒤에만 교체합니다. 선택본 저장·복구에는 기존 PDF 저장 경로를 사용합니다.

한글이 빈칸으로 변환되는 것을 막기 위해 변환마다 로컬 한글 글꼴을 전용 프로필에 연결합니다. macOS의 Apple Gothic, Windows의 맑은 고딕, Linux의 Noto CJK 또는 나눔고딕을 자동으로 찾습니다. Linux 서버에는 해당 글꼴을 설치해야 합니다. 다른 글꼴이나 원본과 동일한 글꼴이 필요하면 `.env.local`의 `EDUFLOW_OFFICE_FONT_FILES`에 한글을 지원하고 사용 권한이 있는 `.ttf`·`.otf`·`.ttc` 파일의 절대 경로를 지정하세요(여러 파일은 macOS/Linux에서 `:`, Windows에서 `;`로 구분). 지정한 글꼴이 없거나 읽을 수 없으면 빈 변환본을 만들지 않고 안내합니다. 글꼴 파일은 서버의 임시 프로필에서만 사용한 뒤 삭제하며 Git이나 AI에 전송하지 않습니다. 이미 글자가 빠진 상태로 저장된 PPT 선택본은 원본 PPT를 다시 불러와야 합니다.

## 한글(HWP/HWPX)

HWP 5(.hwp)·HWPX(.hwpx)도 **업로드 → 전체 페이지 수 확인 → 스크롤 미리보기 → 전체 / 일부 선택 → 이 영역 사용 → 제작 요청 → 선택한 HWP/HWPX로 생성** 순서로 같은 화면을 사용합니다. 한글 문서를 로컬 [rhwp](https://github.com/edwardkim/rhwp) v0.8.7(MIT)로 PDF로 변환하며, 사용한 한글 글꼴을 변환 PDF에 포함해 미리보기에서 글자가 빠지지 않도록 합니다. 원본 HWP/HWPX나 전체 변환본은 AI에 보내지 않고 선택한 페이지만 기존 PDF 호환 경로로 전달합니다. 모델·사용량 한도는 그대로입니다. 선택본·원본 파일명·선택 번호·제작 요청은 새로고침 후 복구됩니다. 다른 페이지를 선택하려면 원본 파일을 다시 올려야 합니다.

팀원 PC에서는 한 번 `npm run setup:hwp`를 실행하세요. macOS Intel/Apple Silicon, Linux x64/arm64, Windows x64의 공식 바이너리를 고정된 SHA256으로 검증하여 프로젝트의 `.eduflow-private/tools/rhwp`에 설치하고 라이선스 안내를 보관합니다. 전역 설치와 한컴 유료 라이선스는 필요하지 않습니다. 다른 설치 경로는 `.env.local`의 `EDUFLOW_HWP_CONVERTER_PATH`로 지정합니다. 한글 글꼴은 PPT와 동일한 `EDUFLOW_OFFICE_FONT_FILES` 설정을 사용합니다. 다른 대체 글꼴을 쓰는 경우 실제 글꼴 이름을 `EDUFLOW_HWP_FALLBACK_FONT`에 지정할 수 있습니다. 설치된 바이너리·다운로드 캐시·글꼴은 Git에 포함하지 않습니다.

한글 변환은 한 번에 하나, 최대 2분이며 성공·실패·취소 시 임시 원본/변환본/글꼴을 삭제합니다. HWPX 압축 구조·암호·비정상 압축 확장과 변환 결과를 검사하고 최대 200페이지까지 불러옵니다. HWP 3 등 구형 형식, 암호·보호 문서, 일부 특수 개체는 지원되지 않을 수 있으므로 한글에서 PDF 또는 HWPX로 다시 저장해야 합니다. 변환 시 글꼴·복잡한 표·배치·쪽 나눔이 한글 앱과 달라질 수 있으므로 미리보기를 확인해야 합니다. 페이지 번호는 변환된 미리보기 기준이며, 매크로 실행·편집 기능은 제공하지 않습니다.

## Word·TXT

Word·TXT의 부분 찾기는 문서 제목·본문의 텍스트 검색입니다. 자연어 요청에서 주제 표현을 추출하지만, 의미 검색이나 OCR을 제공하지 않습니다. 같은 표현의 제목이 있으면 제목 구간을 우선 선택하며, 찾은 내용을 사용자에게 표시하고 AI는 선택 원고와 제작 요청을 받아 초안을 생성합니다. 원고가 20,000자를 넘으면 제작할 부분을 먼저 찾아야 합니다. 없는 주제나 20,000자 초과 구간은 임의로 만들어 내거나 잘라내지 않고 안내합니다. 구형 DOC는 PDF 또는 DOCX로 변환해야 합니다.

## 교육 대상 선택지 변경

초등·중등 대상은 새 설정 선택지에서 제외했습니다. 이전 저장 작업은 기존 장면과 생성 당시 교육대상을 보존하며, 현재 생성 설정의 예전 대상만 일반 방문자 또는 산업현장 근무자로 변경합니다. 설명 난이도 선택지는 기존 쉬움·보통·심화를 유지합니다. 대상·난이도별 실제 생성 품질은 후속 평가가 필요합니다.

## 무료 데모의 설정 반영 방식

무료 데모에서는 대상과 난이도가 목적/검토 안내 템플릿에, 톤은 나레이션의 도입부에 반영됩니다. 강조 키워드와 추가 요청은 제작 메모로 반영됩니다. **무료 데모는 실제 어휘 재작성·추론·영어 번역을 수행하지 않습니다.** 영어 선택 시 안내 템플릿만 영어로 바뀌며 원문은 그대로 유지됩니다. 모든 생성 장면은 검토 필요로 시작합니다. 장면 미리보기는 실제 제목·자막을 사용하는 배치 예시이며, 생성 이미지나 완성 영상이 아닙니다.

## 브라우저 저장과 복구

이전 브라우저 작업을 이어받도록 localStorage 키 `frame-studio-v1`을 유지합니다. 저장된 내용은 같은 브라우저와 같은 주소에서 열립니다. `localhost`와 `127.0.0.1`, 다른 포트는 서로 다른 저장 공간입니다.

삭제한 훈민정음 예제의 구형 12장면 결과가 브라우저에 남아 있는 경우, 제목·12개 장면 제목이 모두 일치하는 결과만 한 번 정리합니다. 현재 원고·첨부 자료·제작 요청·설정은 보존하고 입력 화면을 엽니다. 정리 전 저장 원본은 같은 브라우저의 `eduflow-retired-hunmin-backup-v1`에 보관하며, 다른 스토리보드와 이후 새로 생성한 결과는 유지합니다.

저장된 작업을 복구하지 못하면 자동 저장과 생성을 중지하고 기존 원본을 보존합니다. 오류 안내의 **저장 원본 다운로드**로 보관한 뒤 **새 스토리보드 → 초기화하고 시작**으로 새 작업을 시작할 수 있습니다. 다운로드 파일은 복구를 위한 원본 보관용이며, 현재 앱에는 JSON 가져오기 기능이 없습니다. 장면 시간은 1~600초의 정수로 저장하며 소수 입력은 반올림합니다.

## 실패 후 다시 시도

생성 실패 후 **다시 시도**는 실패 당시의 원고·설정·대상 장면·추가 요청을 그대로 사용합니다. 다른 장면을 선택하거나 수정·재정렬해도 원래 대상만 교체합니다. 대상 장면을 수정·삭제했거나 전체 생성 실패 이후 스토리보드를 수정한 경우 재시도를 중지하고, 현재 내용에서 생성을 새로 요청하도록 안내합니다.
