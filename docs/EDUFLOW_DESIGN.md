# EduFlow 디자인 가이드

작성일: 2026-09-29. 사용자 첨부 Expo 디자인 분석을 Frame 스토리보드 작업 화면에 맞게 재해석했다. 구현 기준은 `app/globals.css`의 공통 토큰이다.

## 방향

작업자가 원고를 해석하고 장면을 설계·검토하는 능률을 높이는 작업 공간. 작업자가 내용을 직접 판단하고 수정하기 쉽도록, AI 제안과 대조할 근거를 필요한 위치에 둔다. 기존 왼쪽 탐색, 상단 3단계 흐름, 원고·설정의 2열 구성, 장면 목록·편집의 2열 구성을 유지한다. 반복 사용에서는 작업 도구가 먼저 보이도록 40px 높이의 제목·행동 줄을 사용한다. 큰 소개 배너, 장식용 목업, 사이드바와 하단의 홍보 문구는 표시하지 않는다. 초보자 안내는 사용 가이드에서 필요할 때 연다.

## 시각 언어

| 역할 | 토큰 | 값 |
| --- | --- | --- |
| 기본 바탕 | `--canvas` | #ffffff |
| 보조 바탕 | `--canvas-soft` | #fafafa |
| 선택 상태·배지 | `--surface` | #f0f0f3 |
| 제목·본문 강조 | `--ink` | #171717 |
| 본문·안내 | `--body` | #60646c |
| 보조 문구 | `--muted` | #74777e |
| 주요 버튼 | `--primary` | #000000 |
| 버튼 상호작용 | `--primary-active` | #1a1a1a |
| 구분선 | `--hairline` | #ededf0 |
| 입력·카드 테두리 | `--hairline-strong` | #dcdee0 |

주요 행동은 검정 버튼, 보조 행동은 흰 바탕과 테두리로 구분한다. 작업 공간을 차지하던 하늘색 소개 배경은 제거했다. 흰 바탕에서 읽기 어렵던 밝은 회색·보라색 안내 문구는 대비를 높인다. 검토 상태는 색과 함께 아이콘·텍스트를 표시한다.

## 글꼴과 크기

- Inter: 영문·숫자, 400/500/600. 한글은 Apple SD Gothic Neo, Noto Sans KR, 시스템 글꼴 순으로 표시한다.
- JetBrains Mono: 장면 번호, 단계 안내, 근거 식별자 등 짧은 구조 정보.
- 입력·편집 화면 제목 22px(모바일 19px), 섹션 제목 15–18px, 본문 13–16px.
- 주요 제목은 600, 본문 400. 한글 제목은 단어를 유지하고, 긴 사용자 입력은 안전하게 줄바꿈한다.
- 글꼴 파일은 프로젝트에 저장하며 방문 시 외부 글꼴 요청을 하지 않는다. 라이선스는 `public/fonts/*-OFL.txt`에 포함한다.

## 크기와 간격

4px 단위를 사용한다. 입력·버튼 모서리 8px, 카드 12px. 기본 카드 간격 20–24px, 내부 여백 20–24px. 단계 탐색 높이 64px, 화면 제목 줄 40px와 아래 여백 16px. 버튼 높이 40px, 주요 행동과 모바일 기본 입력 44px. 작업 화면에는 참고 문서의 96px 마케팅 섹션 여백보다 압축된 간격을 적용한다.

## 주요 화면

1. 원고 입력: 간결한 제목·사용 가이드 → 원고 입력과 생성 설정 → 조건 요약·생성 버튼. 빈 상태에서도 붙여넣기, PDF·Word·TXT 불러오기, 샘플 원고가 명확하게 보인다. 업로드 문서는 제작 요청 → 제목·본문 검색 → 원고 확인 → 생성 순서로 사용한다. 실제 AI와 데모의 데이터 전송 안내를 구분한다.
2. 장면 편집: 전체 개요 → 장면 목록 → 선택 장면 편집. 제목 아래에 목적·예상 시간을 바로 편집하고, 화면 설명·나레이션·자막을 작성한다. 검정 배경의 제목·자막 배치 예시는 제공하지 않는다. 원문 근거·보강 자료·시각자료는 각각 제목, 출처 정보, 내용 순서로 배치하고 해당 제목 오른쪽의 ‘대조하기’로 원본을 확인한다. 시각자료는 표 또는 그림을 한 번만 표시하며 같은 내용을 인용문으로 반복하지 않는다. 참고 이미지·근거·검토 메모는 같은 섹션 간격과 제목 규칙을 사용한다.
3. 내보내기: 파일명과 현재 장면 수를 확인한 뒤 PDF 스토리보드·Markdown·전체 복사 중 선택한다. 검토 필요 장면 수를 함께 안내한다.

참고 자료의 마케팅 목업·슬로건은 반복 작업 화면에서 사용하지 않는다. 안내를 접거나 ‘다시 보지 않기’를 설정하는 추가 조작 없이 항상 같은 압축된 작업 화면으로 시작한다. 별도의 랜딩 페이지나 가격표·마케팅 탐색을 추가하지 않는다.

## 반응형·접근성

- 1200px 이하: 사이드바와 패널 여백을 줄인다.
- 1000px 이하: 입력·설정과 장면 목록·편집을 세로로 배치한다. 장면 목록은 가로 스크롤한다.
- 760px 이하: 탐색 메뉴를 접고 메뉴 버튼으로 연다.
- 480px 이하: 설정·편집 필드를 한 열로 정리하고 주요 버튼을 전체 너비로 배치한다.
- 입력은 명확한 레이블, 포커스 테두리, 최소 길이 안내를 제공한다. 단계와 현재 메뉴는 보조 기술에도 현재 상태를 전달한다.
- 애니메이션 감소 설정을 존중한다. 로딩·오류·저장 상태는 텍스트로 확인할 수 있다.

## 데이터 연속성

2026-10-09 고객 대상 조정: 호롱불의 주요 교육대상은 산업현장 근무자, 현장 방문자(일반인·기업 관계자·외부 하청업체), 외국인 근로자다. 새 설정에서 초등·중등을 제외하고 이 다섯 선택지로 교체한다. PRD의 해결하려는 문제 3번인 **학습 대상과 난이도에 따라 콘텐츠를 매번 새로 구성하는 문제**를 기준으로 대상과 설명 난이도를 별도로 반영한다. 이번 변경에서는 난이도 선택지를 유지하며, 대상·난이도 조합에 따른 용어·문장 길이·행동 안내의 품질 평가는 후속 작업으로 남긴다. 외국인 근로자 선택이 출력 언어를 자동으로 바꾸지는 않는다.

브랜드 변경과 무관하게 저장 키 `frame-studio-v1`, Board/Scene 구조, 생성 API 계약을 유지한다. 생성은 기존 원문 발췌 데모이며 실제 AI 연동은 별도 작업이다.

## 지식베이스 작업 화면 (2026-10-30)

스토리보드와 같은 공통 토큰·글꼴·왼쪽 탐색을 사용한다. 상단에는 짧은 제목과 주요 행동인 ‘자료 등록’만 둔다. 등록 폼은 별도 대화상자에서 파일/본문 방식을 선택하고, 페이지 범위와 발행 정보는 필요할 때 펼친다.

등록 자료 화면은 ‘자료 목록 → 선택한 자료 상세’로 구성한다. 목록에는 제목, 검색 상태, 확인할 페이지 수만 표시하고 항목 전체를 선택 버튼으로 사용한다. 상세 안의 ‘표·그림 / 판독 확인 / 자료 정보’로 작업을 구분한다. 검토 대기 자료를 선택하면 판독 확인을 먼저 연다. 원본 출처는 자료 정보에, 원본 페이지 비교는 해당 표·검토 페이지 옆에 둔다. 검색 제외와 영구 삭제는 ‘자료 관리’에 모으고 삭제는 결과를 설명하는 확인창을 거친다.

표·그림과 판독 확인은 페이지 선택기와 이전/다음 버튼으로 한 번에 한 페이지씩 표시한다. AI 분석은 해당 페이지에서만 실행하고 버튼에 비용 상한을 표시한다. 무료 구조 재판독은 문제 해결 안내 안에 둔다. 표·그림 미감지 페이지는 기본 목록에서 숨기며 필요하면 포함할 수 있다. 승인·실패·분석 결과는 작업한 상세 영역에 표시한다. 판독 초안은 같은 화면에서 탭이나 자료를 바꾸어도 유지되지만, 새로고침 전 서버에 반영해야 한다.

근거 검색은 별도 작업 탭으로 제공한다. 검색어와 결과 수, 출처 페이지를 표시하고 자료 상세로 연결한다. 1000px 이하에서는 자료 목록을 가로 카드로 배치하고, 자료 선택 시 상세 영역으로 이동해 포커스를 준다. 넓은 표만 자체 영역 안에서 좌우 스크롤되며 페이지 전체는 넘치지 않도록 한다. 760px 이하에서는 데스크톱 사이드바 대신 스토리보드 복귀 링크를 표시한다.


## PDF 스토리보드 출력 (2026-10-31)

### 장면별 콘티 이미지

장면 편집의 ‘콘티 이미지’에서 화면 설명, 원문 근거, 연결된 RAG 발췌로 16:9 제작용 이미지를 생성한다. 공통 그림체와 인물·배경 설정은 문서에 저장하며 장면별 수정 요청은 선택 장면에만 적용한다. 현재 첨부 또는 생성 이미지를 다음 생성의 인물·구도 참고로 보낼 수 있다. 원본 표·그림 추천과 생성 이미지는 별도 영역으로 구분하며, 생성 이미지를 원문 증거로 취급하지 않는다.

사용자는 ‘모델 연결’에서 기존 OpenAI 키 또는 Gemini 팀 키를 통한 유료 이미지 생성을 켠다. 현재 글 생성 방식이 OpenAI이고 해당 키가 있으면 OpenAI 이미지를 사용하며, 그 외에는 Gemini 팀 키, 기존 OpenAI 키 순서로 연결을 선택한다. 텍스트 생성 모델 선택은 바뀌지 않는다. 호출 전 생성 버튼 옆에 연결 상태, 최대 비용, 임시 예약액, 실제 전송 대상을 표시한다. 생성 버튼과 연결 안내를 미리보기 위에 둔다. 이미지 호출은 텍스트 생성과 동일한 영구 비용 장부와 하루 $1·월 $5 상한을 공유하며 자동 재시도하지 않는다. 생성 실패·취소·저장 실패·요청 중 장면 변경 시 기존 이미지를 유지한다. 새 생성 이미지는 검토 필요 상태로 저장한다.

콘티 생성 단계는 원문 전체와 지식베이스를 다시 검색하지 않는다. 선택 장면에 이미 연결된 원문 인용과 RAG 발췌를 화면 설명·나레이션과 함께 전달한다. PDF 원본 페이지나 RAG 표·그림의 실제 픽셀은 자동 첨부하지 않으며, 사용자가 선택한 현재 이미지만 인물·구도 참고로 첨부한다. OpenAI 참고 이미지는 비용을 제한하기 위해 최대 512px 썸네일로 보낸다.

이미지 원본은 브라우저 IndexedDB, 생성 모델·시각·입력 근거 기록은 문서 초안에 저장한다. 장면 목록은 저장된 이미지 썸네일을 보여준다. 원문·RAG 근거 또는 공통 설정 변경 후에는 기존 이미지의 재생성을 안내한다. PDF에는 이미지와 ‘AI 생성 콘티 (원본 증거 아님)’을 함께 표시한다. PNG 개별 내려받기와 기존 이미지 첨부도 유지한다.

콘티는 최종 삽화보다 화면 설명의 인물·시선·동작·카메라 거리와 자료 배치를 우선한다. 흑백 콘티는 단순한 선화로 요청하며 기존 OpenAI low 품질을 유지한다. 시각자료 추천의 실제 자료 ID와 연결된 ‘추천 시각자료 N · 표/그림’ 스티커를 앱에서 그린다. 생성 모델에는 자리의 백분율 좌표만 전달하고 해당 영역을 비우도록 요청한다. AI 배경의 구도를 보장하는 것은 아니지만 스티커 위치·크기는 AI 출력과 독립적으로 고정된다. 원본 표·그림의 내용을 다시 그리지 않는다.

추천 자료는 화면 설명을 참고한 초기 배치로 표시한다. 왼쪽·오른쪽·전체·하단 빠른 배치, 드래그·방향키 이동, 백분율 위치·크기 편집과 표시 해제를 지원한다. 수정 위치는 장면의 visualPlacements에 저장하며 문서 복원·장면 이동·텍스트 재생성 때 유지한다. 제거된 자료의 스티커는 표시하지 않는다. 스티커 조정·합성과 PNG/PDF 저장에는 AI 호출이 없다. 배경 이미지가 없어도 자료 배치 콘티를 저장·출력할 수 있다. PNG는 미리보기와 같은 SVG 스티커를 합성하고 PDF는 같은 백분율 좌표와 자료 번호·제목·페이지 범례를 그린다.

미리보기에서 선택한 스티커 오른쪽 아래 모서리를 끌어 크기를 바꿀 수 있다. 왼쪽 위 위치는 고정하고 화면 경계와 최소 크기에서 제한한다. 크기 조절 모서리는 방향키와 Shift+방향키를 지원한다. 콘티 배경은 모서리 또는 ‘콘티 배경 크기’ 슬라이더로 20~100% 범위에서 비율을 유지한 채 중앙에 배치하며 ‘화면에 맞춤’으로 복원한다. 이미지의 scalePercent를 초안에 저장하고 PNG·PDF는 같은 좌표 계산으로 실제 삽입 크기를 적용한다. 스티커와 배경의 크기는 각각 독립적이며, 조절 손잡이·테두리는 출력물에 포함하지 않는다.

### PDF 레이아웃

영상 제작용 A4 가로 문서는 왼쪽 참고 이미지·출처·장면 정보, 오른쪽 자막·내레이션·연출 가이드를 유지한다. 웹과 같은 흰 바탕, 중립 회색 본문·구분선, 검토 상태 색상과 텍스트를 사용한다. 웹 전용 사이드바·버튼·반응형 규칙은 인쇄물에 적용하지 않는다.

인쇄 본문은 10pt, 줄 간격은 14pt, 문서 제목은 14pt로 구분하고 로컬 한글 글꼴을 PDF에 포함한다. 장면은 새 페이지에서 시작하며 긴 제목·출처·목적·본문·검토 사유는 생략하지 않고 필요한 만큼 다음 페이지로 이어진다. 가로·세로 이미지는 비율을 유지해 전체가 보이도록 배치하며 이어지는 페이지에도 같은 장면 이미지를 표시한다. 자동 검증 외에 PDF 전체 페이지를 렌더링해 글자·이미지 잘림과 겹침을 확인한다.
