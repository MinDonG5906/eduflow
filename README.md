## 기술 구성

- Next.js 16.3.5 App Router, React 19, TypeScript
- shadcn/ui의 Base UI 기반 Button, Input, Textarea, Dialog 컴포넌트
- Tailwind CSS 4, Lucide 아이콘
- Zod 입력/출력 검증, Next.js Route Handler
- localStorage 자동 저장 및 복구
- 로컬 Inter / JetBrains Mono 글꼴, 한글은 시스템 한글 글꼴 사용

개발 서버와 빌드는 Webpack을 사용합니다. 이 환경에서 Turbopack 개발 서버가 스타일 파일의 최신 변경을 반영하지 않는 현상을 확인하여, 재시작·검증한 Webpack으로 통일했습니다.

## 프로토타입 범위와 한계

**실제 AI 모델은 연결되어 있지 않습니다.** `/api/generate`에서 원문을 나누는 결정론적 데모를 실행합니다. API 키 없이 사용할 수 있고 외부 모델에 원고를 전송하지 않습니다. 원고·결과를 서버 DB에 저장하지 않습니다.

대상과 난이도는 목적/검토 안내 템플릿에, 톤은 나레이션의 도입부에 반영됩니다. 강조 키워드와 추가 요청은 제작 메모로 반영됩니다. **실제 어휘 재작성, 추론, 요약 품질, 영어 번역은 구현하지 않았습니다.** 영어 선택 시 안내 템플릿만 영어로 바뀌며 원문은 그대로 유지됩니다. 모든 생성 장면은 검토 필요로 시작합니다. 장면 미리보기는 실제 제목·자막을 사용하는 배치 예시이며, 생성 이미지나 완성 영상이 아닙니다.

AI 출력 형식이 잘못되면 한 번 재시도하고 기존 결과를 보존합니다. 현재는 전체 응답 검증 방식으로, 일부 장면만 성공하는 실제 모델 응답의 부분 복구는 후속 구현 범위입니다. AI 원본 전체 버전은 따로 저장하지 않으며 수정 필드 메타데이터를 기록합니다. 편집 장면은 최대 30개까지 지원합니다.

실제 모델을 연결하려면 `app/api/generate/route.ts`의 데모 호출을 서버 전용 모델 어댑터로 교체하고, 구조화 응답과 장면별 복구, 원문 충실도, 교육 대상별 표현 및 번역 품질을 검증해야 합니다. 이 프로젝트는 UX 검증용이며 PRD의 출시 기준 전체 통과를 의미하지 않습니다.
