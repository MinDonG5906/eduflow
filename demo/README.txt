EduFlow 기업 체험용 데모

처음 AI를 연결하는 담당자는 함께 있는 ‘AI_API_연결가이드.txt’를 읽어 주세요.
API 키 준비 → 화면에서 연결 → 글·이미지 생성 확인 → 비용 관리와 오류 해결을 안내합니다.
기존 예제만 열어 편집·출력할 때는 API 연결이 필요하지 않습니다.
이 패키지의 실제 AI 한도는 하루 $10·월 $20입니다.
현재 화면 일부의 ‘하루 $5·월 $10’ 표시는 실제 설정과 다릅니다. 자세한 내용은 연결 가이드를 확인하세요.

1. ZIP을 모두 풀어 쓰기 가능한 폴더에 보관하세요.
2. Node.js 24가 설치되어 있어야 합니다. https://nodejs.org/
3. Windows는 Windows-Start.cmd, macOS는 macOS-Start.command를 실행하세요.
   macOS에서 실행 권한이 없으면 터미널에서 sh 를 입력한 뒤 파일을 끌어놓고 Enter를 누르세요.
4. 첫 실행은 인터넷을 통해 구성 요소를 설치하고 프로그램을 준비합니다. 몇 분 걸릴 수 있습니다.
5. http://127.0.0.1:3210/ 에서 ‘원고 및 설정’ 화면이 바로 열립니다.
   처음 사용하는 브라우저에는 동봉된 예제가 자동으로 준비됩니다.
   기존 저장 작업이 있으면 그대로 유지하며, 왼쪽 ‘스토리보드’에서 결과를 볼 수 있습니다.
6. 사용 중에는 실행 창을 열어 두세요. Ctrl+C로 서버를 종료할 수 있습니다.

포함 범위
- 지식베이스 원문 PDF, 추출 글, 그림·표 구조, 검색 데이터, 페이지 판독 기록.
- 기존 문서·구간 ID를 유지하여 저장된 근거 연결을 보존합니다.
- 예제가 담긴 경우 문장별 근거 분류·판단 보류·사용자 선택, 이미지, 자막·자료 배치도 포함합니다.
- 작업 묶음은 현재 작업 1개입니다. 브라우저에 남아 있지 않은 과거 작업은 복구하지 않습니다.
- 선택 원고는 저장된 선택 페이지만 포함합니다.
- API 키, 개인 모델 연결, 비용 장부, 개발 로그는 포함하지 않습니다.

체험 범위
- 기존 결과 열기, 근거 원문 확인, 편집, 이미지 배치, PDF·TXT 출력은 새 AI 호출 없이 사용할 수 있습니다.
- 새 AI 스토리보드·이미지 생성은 인터넷과 별도 모델 연결이 필요합니다.
- 기본 원문 발췌 데모 모드의 새 생성은 RAG를 사용하지 않습니다. RAG 기반 새 생성은 AI 연결 후 체험하세요.
- 기존에 등록한 PDF·그림·표 확인은 변환 도구를 새로 설치하지 않아도 가능합니다.
- 새 PPT/Word 입력은 LibreOffice, 새 HWP/HWPX 입력은 rhwp가 추가로 필요할 수 있습니다.
- Windows와 macOS용 구성 요소는 첫 실행 때 각 PC에 맞춰 설치합니다. 서명된 독립 실행 설치 파일은 아닙니다.
- 내부 자료가 포함된 패키지이므로 체험 대상에게만 전달해 주세요.

작업 보존
- 편집 내용과 생성 이미지는 해당 PC 브라우저에 저장됩니다.
- 기업 체험용 패키지에는 ‘데모 전달’ 메뉴가 표시되지 않습니다. 결과는 PDF·TXT로 내보낼 수 있습니다.
- app/.eduflow-private 는 전달된 지식베이스입니다. 삭제하지 마세요.
- 후속 작업 중 API 키를 입력했다면 폴더 전체를 재배포하지 마세요. 제작자의 패키지 생성 도구로 새로 만들어야 합니다.
