EduFlow 기업 체험용 — AI API 연결 안내
작성 기준: 2026-11-02 / 동봉된 EduFlow-Demo 패키지

API 키는 에듀플로우가 기업의 AI 계정으로 생성 요청을 보낼 때 사용하는 비밀 인증값입니다.
프로그램을 새로 개발할 필요는 없습니다. 아래 순서대로 키를 발급받아 화면에 입력하면 됩니다.
이 안내는 글과 이미지 생성을 함께 체험할 수 있는 OpenAI 연결을 기준으로 합니다.

빠른 순서
① 데모 실행 → ② OpenAI Platform에서 결제·키 준비 → ③ ‘모델 연결’에서 키 저장
→ ④ 짧은 원고로 글 생성 확인 → ⑤ 이미지 생성 켜기 → ⑥ 이미지 1장 확인

1. 기존 예제만 보려면 API 연결이 필요 없습니다
------------------------------------------------------------
ZIP을 모두 풀고 ‘먼저읽기.txt’에 따라 Node.js 24 설치와 첫 실행을 마칩니다.
브라우저 주소: http://127.0.0.1:3210/
‘원고 및 설정’ 화면이 바로 열립니다. 처음에는 동봉된 예제가 자동으로 준비됩니다.
기존 작업이 있으면 유지됩니다. 저장된 결과는 왼쪽 ‘스토리보드’에서 확인하세요.
저장된 지게차 예제, 근거 원문, 이미지, 편집과 PDF·TXT 출력을 체험할 수 있습니다.
이 작업에는 새 AI 생성 비용이 들지 않습니다.
새 원고로 AI 스토리보드를 만들거나 이미지를 새로 만들 때 다음 연결 과정이 필요합니다.

2. 기업 담당자가 준비할 것
------------------------------------------------------------
• 인터넷이 연결된 데모 실행 PC와 기업에서 사용할 OpenAI Platform 계정.
• 해당 계정의 API 프로젝트·키·결제를 관리할 담당자.
• API 사용에 필요한 결제 수단 또는 사용 가능한 크레딧.
• AI 서비스로 전송해도 되는 테스트 원고. 처음에는 아래의 짧은 예문을 사용하세요.

ChatGPT 로그인이나 구독 여부만으로 API 결제 준비가 끝났다고 판단하지 마세요.
OpenAI Platform에서 해당 프로젝트에 적용되는 결제 상태와 사용 가능한 크레딧을 확인합니다.
비용은 등록한 API 키가 속한 계정·프로젝트에 발생하며, 제작자 계정으로 자동 청구되지 않습니다.
새 AI 생성 시 원고와 검색된 근거가, 이미지 생성 시 장면·근거·선택한 참고 이미지가
외부 AI 서비스로 전송됩니다. 기업에서 허용한 자료로 체험하세요.

3. OpenAI Platform에서 결제와 키 준비
------------------------------------------------------------
① https://platform.openai.com/ 에 로그인합니다.
② 에듀플로우 체험에 사용할 프로젝트를 선택합니다. 필요하면 관리자가 체험용 프로젝트를 만듭니다.
③ Settings(설정)의 Billing(결제)에서 결제 상태를 확인합니다.
   화면에 결제 수단 등록 또는 크레딧 추가가 필요하다고 나오면 기업 담당자가 진행합니다.
   충전액·자동 충전 여부를 확인하고, 안내되는 실제 금액에 동의한 뒤 진행하세요.
④ API keys 화면을 엽니다: https://platform.openai.com/api-keys
   키 생성 버튼(Create new secret key 등)을 누르고 ‘EduFlow Demo’처럼 구분할 이름을 지정합니다.
   선택한 프로젝트가 맞는지 확인하고 키를 생성한 뒤 복사합니다.
⑤ 키를 다음 단계의 에듀플로우 입력칸에 붙여넣습니다.
   키는 비밀번호처럼 취급합니다. 메일·메신저·스크린샷·지원 요청에 전체 키를 넣지 마세요.

메뉴 이름은 계정 권한과 OpenAI 화면 개편에 따라 달라질 수 있습니다.
결제나 키 생성 메뉴가 보이지 않으면 기업의 OpenAI 관리자에게 요청하세요.
제한된 권한의 키를 사용하는 경우, 관리자가 글 생성(Responses)·입력 토큰 계산과
이미지 생성·편집에 필요한 권한 및 해당 모델 접근 권한을 확인해야 합니다.

4. 에듀플로우에서 API 연결
------------------------------------------------------------
① 편집 화면(http://127.0.0.1:3210/) 오른쪽 위 ‘데모 모드’를 누릅니다.
   이미 다른 연결을 선택했다면 해당 AI 이름이 표시됩니다. 이 버튼이 ‘모델 연결’을 엽니다.
② ‘OpenAI API 키’를 선택합니다.
③ ‘OpenAI API 키’ 입력칸에 복사한 키를 붙여넣습니다.
④ ‘유료 호출에 동의합니다’ 항목을 확인하고 체크합니다.
⑤ ‘키 저장하고 사용’을 누릅니다.
⑥ ‘저장된 키’에 끝 일부만 표시되고, 오른쪽 위 연결 표시가 ‘OpenAI API’인지 확인합니다.

키 저장만으로 유료 생성 테스트가 실행되지는 않습니다.
저장 성공은 키의 유효성·잔액·모델 권한까지 검증했다는 뜻이 아닙니다. 다음 단계로 확인하세요.
OpenAI 글 모델은 패키지에서 정해져 있어 이 화면에서 따로 고르지 않습니다.
이 패키지의 글 모델은 gpt-5.4-mini-2026-03-17입니다.
API 키를 저장하는 방식이면 일반 사용자가 설정 파일을 편집할 필요가 없습니다.

5. 글 생성 연결 확인 — 소액의 API 비용 발생
------------------------------------------------------------
① 보존할 작업이 있다면 ‘데모 전달’에서 ‘현재 작업 묶음 저장’으로 먼저 내려받습니다.
② ‘새 스토리보드’를 열고 아래 테스트 원고를 입력합니다.

   오늘은 사내 교육자료를 정리하는 방법을 알아봅니다.
   먼저 자료의 제목과 작성일을 확인합니다.
   다음으로 교육 대상과 핵심 내용을 정리합니다.
   마지막으로 담당자가 검토한 자료를 공유합니다.

③ 교육 대상·분량 등 생성 조건을 정하고 ‘스토리보드 생성’을 누릅니다.
   PDF 입력 화면에서는 ‘생성하기’로 표시될 수 있습니다.
④ 장면별 나레이션과 자막이 생성되는지 확인합니다.
⑤ OpenAI Platform의 Usage(사용량)에서도 프로젝트별 사용 내역을 확인합니다.
   https://platform.openai.com/usage

이 짧은 원고는 연결 확인용입니다. 관련 RAG 근거가 없을 수 있으며, 근거 카드가 없다는
이유만으로 연결 실패는 아닙니다. RAG 체험은 동봉 예제 또는 관련 교육 원고로 진행하세요.
‘무료 데모’가 선택된 상태의 새 생성은 RAG를 사용하지 않습니다.

6. 이미지 생성 연결 확인 — 이미지 생성 비용 별도 발생
------------------------------------------------------------
① 다시 ‘모델 연결’을 엽니다.
② 아래 ‘스토리보드 이미지 생성’에서 연결이 ‘OpenAI’로 표시되는지 확인합니다.
③ 장면 내용·연결 근거·참고 이미지 전송 및 유료 생성 동의 항목을 체크합니다.
④ ‘스토리보드 이미지 생성 켜기’를 누릅니다.
⑤ 창을 닫고 장면 편집에서 장면 하나를 골라 ‘이미지 생성’을 누릅니다.
⑥ 이미지가 표시되면 연결 확인이 끝났습니다.

이미지도 저장한 OpenAI 키를 사용합니다. 이 패키지의 이미지 모델은
gpt-image-2-2026-04-21이며, 모델 사용 가능 여부는 계정·프로젝트 권한에 따라 다릅니다.
‘이미지 다시 생성’을 누를 때마다 새로운 유료 요청이 발생합니다.
사용하지 않을 때는 ‘모델 연결’에서 ‘이미지 생성 끄기’를 누를 수 있습니다.

7. 이 전달 패키지의 비용 한도
------------------------------------------------------------
하루 총한도: $10 / 월 총한도: $20
최근 1시간 요청 한도: 5건 / 동시 처리: 1건
OpenAI 글 생성 요청당 한도: $0.10 / 이미지 생성 요청당 한도: $0.30
요청당 한도는 정액 요금이 아닙니다. 글·근거 검증·이미지 등 AI 작업은 공통 예산을 사용합니다.

주의: 현재 화면 일부에는 ‘하루 $5·월 $10’이라고 고정 표시되어 있습니다.
동봉 패키지의 실제 설정은 하루 $10·월 $20입니다. 화면 문구보다 이 실제 설정이 적용됩니다.

• 앱은 실제 청구액 대신 보수적으로 계산한 호출 비용으로 예산을 관리합니다.
  다음 요청을 위한 비용까지 확보할 수 없으면 실제 청구액이 더 적어도 생성이 막힐 수 있습니다.
• 일 한도는 한국 시간 매일 오전 9시, 월 한도는 매월 1일 오전 9시에 새 기간으로 바뀝니다.
• 기존 결과 열기·직접 편집·PDF 출력에는 생성 예산이 들지 않습니다.
• 이 한도는 설치된 데모별입니다. 여러 PC 또는 다른 앱에서 같은 키를 사용한 금액을
  모두 합산해 제한하지는 않습니다. 계정 전체 비용은 Platform의 Usage에서도 확인하세요.
• OpenAI 프로젝트 설정의 Limits에서 월 사용 알림과 지출 한도를 별도로 관리할 수 있습니다.
  알림만 설정하면 호출은 계속됩니다. 호출 차단이 필요하면 ‘Enforce a hard limit’ 적용 여부를
  관리자와 확인하세요. 제공사 측 차단 반영에는 지연이 있어 소액 초과가 생길 수 있습니다.

한도 변경이 필요하면 제작자 또는 기업 운영 담당자에게 요청하세요.
운영 담당자 참고: 데모의 app/.env.local에서 EDUFLOW_AI_DAY_BUDGET_USD와
EDUFLOW_AI_MONTH_BUDGET_USD를 조정한 뒤 실행 창을 종료하고 다시 실행합니다.
시간당 제한은 EDUFLOW_AI_REQUESTS_PER_HOUR이며, 생략 시 5입니다.
설정 변경은 승인된 예산 범위에서만 진행하고, 실제 설정값을 체험자에게 안내하세요.

8. 연결이 안 될 때
------------------------------------------------------------
‘키 저장하고 사용’ 버튼이 눌리지 않음
→ 키가 입력되었는지, 유료 사용 동의가 체크되었는지 확인합니다.

‘AI 키의 권한 또는 결제 잔액을 확인해 주세요’
→ 키를 다시 붙여넣고, Platform의 결제·크레딧·프로젝트 권한을 확인합니다.
  앱에 키가 저장되어 있어도 만료·삭제된 키이거나 사용 권한이 부족할 수 있습니다.

‘설정한 AI 비용 한도에 도달했습니다’
→ 앱 예산이 다음 요청에 부족합니다. 기존 결과는 계속 편집·출력할 수 있습니다.
  다음 기간까지 기다리거나 담당자에게 한도 확인을 요청합니다.

‘생성 요청이 많습니다. 잠시 후 다시 시도해 주세요’
→ 실행 중인 작업이 끝나기를 기다립니다. 최근 1시간 5건에 도달했다면 앞선 요청으로부터
  1시간이 지난 뒤 다시 시도합니다. 제공사 측 요청 제한도 원인이 될 수 있습니다.

‘이 OpenAI 키에서 이미지 모델을 사용할 수 없습니다’
→ 프로젝트의 이미지 모델 접근 권한·결제 설정과 요구되는 조직 인증을 관리자에게 확인합니다.
  글 생성 성공이 이미지 모델 사용 가능까지 보장하지는 않습니다.

‘AI 키·모델·비용 한도 설정을 확인해 주세요’ 또는 계속 생성 실패
→ 키 저장 상태를 확인한 뒤, 발생 시각과 오류 문구를 제작자에게 전달합니다.
  모델 접근 권한 또는 패키지의 모델 설정을 점검해야 할 수 있습니다. API 키 전체는 보내지 마세요.

데모 화면 자체가 열리지 않음
→ API 키 문제가 아닙니다. 실행 창을 열어 두었는지, Node.js 24 설치와 첫 실행 준비가
  완료됐는지 확인하고 http://127.0.0.1:3210/ 로 접속합니다.
  회사 네트워크에서 외부 API 접속이 제한되면 IT 담당자에게 접속 허용 여부를 문의합니다.

9. 체험 종료와 키 관리
------------------------------------------------------------
필요한 작업은 ‘현재 작업 묶음 저장’ 또는 PDF·TXT로 내려받습니다.
키를 이 PC에서 지우려면 ‘모델 연결’ → ‘OpenAI API 키’ → ‘키 삭제’를 누릅니다.
앱에서 삭제하는 것과 OpenAI에서 키를 폐기하는 것은 별개입니다.
체험용 키를 더 쓰지 않으면 관리자가 Platform의 API keys에서도 해당 키를 폐기합니다.
키를 입력한 데모 폴더 전체를 다시 다른 사람에게 전달하지 마세요.
재배포가 필요하면 제작자에게 키가 제외된 새 전달용 패키지를 요청하세요.
