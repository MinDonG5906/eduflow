EduFlow for Windows (64-bit)

1. Extract ALL files from the downloaded ZIP into a writable folder.
2. Double-click EduFlow.exe. Your browser opens at http://127.0.0.1:3000/.
3. Keep the black window open while using EduFlow. Press Enter or close it to stop.

Port 3000 must be free. If Windows blocks an unsigned executable, consult your administrator.
Your browser's saved work belongs to this exact address and browser. Local server data and model settings are stored in app\.eduflow-private; keep this folder when updating or moving the app. Do not share it with others.
PPT conversion requires LibreOffice. HWP/HWPX conversion requires the separately installed rhwp converter; see the project README for details.
